# IPVIO Stream Desktop

This is the Windows desktop port of IPVIO Stream, an IPTV player for your own playlists, built with Kotlin and Compose Desktop. It is licensed under GPL-3.0 (see [LICENSE](LICENSE)) and ships with no channels, playlists, or other content; you supply your own M3U playlists and XMLTV EPG data, and playback requires a local VLC installation. The project does not distribute or embed any copyrighted media. Builds produced from this repository are unsigned, so Windows SmartScreen will warn on first run.
